# Slashlib (iOS 10, jailbreak .deb)

Редактировать: VS Code (любая ОС). Собирать: GitHub Actions (.github/workflows/build.yml) или ./build.sh на Mac.
Настройки API: Sources/Config.swift

## Синхронизация между устройствами (0.7.0)
«Аккаунт → Синхронизация»: закладки, избранное, история («Недавние») и прочитанные главы синхронизируются
через приватный Gist в вашем аккаунте GitHub (нужен токен с правом gist, срок «No expiration»).
Второе устройство вводит тот же токен и подхватывает данные само. Слияние по времени + учёт удалений.

## Что нового в 0.6.0
- Читалка: исправлена белая полоса снизу («подбородок»); страницы теперь на весь экран, панели тёмные и
  лежат поверх. Панели прячутся при листании и по нажатию на центр экрана.
- Панель «Вид» в читалке: режим, фон страницы (чёрный/серый/белый), затемнение, автоскрытие панелей,
  «не гасить экран», быстрый выбор темы (светлая/тёмная/авто).
- «Аккаунт → Оптимизация»: профиль «Телефон» / «Планшет» (размер картинок, кэши, постеры, потоки загрузки).
- Мелкие оптимизации: обложки в списках масштабируются не в главном потоке и кэшируются.

## Что нового в 0.5.0
- Вкладки: Главная · Поиск · Избранное · Закладки · Аккаунт.
- Главная: сверху «Продолжить чтение» с полосой и процентами прочитанной главы, ниже случайные подборки
  по жанрам с тегами в прямоугольниках (пересобираются жестом «потянуть вниз» или кнопкой «Другие»).
- Тёмная тема (светлая / тёмная / авто: ночью с 21:00 до 07:00) — «Аккаунт → Внешний вид».
- MangaLib: переключатель в «Аккаунт → Источники» (добавляет сайт в поиск и подборки).
- Анимации и украшения (плавное появление, блики загрузки, полоски у заголовков, тени, анимация звезды,
  смена вкладок): один переключатель в «Аккаунт → Внешний вид». В энергосбережении выключаются сами.

## Что есть (0.4.0)
- Нижняя панель: Поиск · Избранное · Закладки · Аккаунт.
- Экран тайтла: сворачивающаяся обложка, блок «О тайтле» (описание, жанры, статус…), выбор главы,
  звезда «в избранное», меню «Загрузки» (скачать все/непрочитанные, удалить, порядок глав).
- Скачивание глав для чтения без сети (или свайпом по главе). Список и размер — «Аккаунт → Управление загрузками».
  Если сети нет, на экране тайтла показываются скачанные главы.
- Энергосбережение (вручную или вместе с режимом iOS): меньше разрешение, без предзагрузки и анимаций,
  экран может гаснуть, загрузка в один поток.
- Цвет акцента (Аккаунт → Цвет акцента).
- Оптимизация под устройства с 1 ГБ памяти (iPad mini 2, iPhone 5s/6): страницы режутся на полосы,
  декодируются по одной, кэши ограничены и чистятся сами.
- Читалка: «Лента», «Страницы →», «Страницы ←», зум, закладки, «Недавние», отметки прочитанного.
- Диагностика: журнал действий, причина вылета показывается при следующем запуске.

## Известные ограничения
- WebP на iOS 10 не открывается (нужна отдельная библиотека).
- Эндпоинты неофициальные (см. «ПРОВЕРИТЬ» в Config.swift и API.swift). Особенно: описание тайтла
  (`titleDetails` в API.swift) — если поля не совпадут, блок «О тайтле» покажет только название.
