# Slashlib (iOS 10, jailbreak .deb)

Редактировать: VS Code (любая ОС). Собирать: GitHub Actions (.github/workflows/build.yml) или ./build.sh на Mac.
Настройки API: Sources/Config.swift

## Что есть (0.4.0)
- Нижняя панель: Поиск · Избранное · Закладки · Аккаунт.
- Экран тайтла: сворачивающаяся обложка, блок «О тайтле» (описание, жанры, статус…), выбор главы,
  звезда «в избранное», меню «Загрузки» (скачать все/непрочитанные, удалить, порядок глав).
- Скачивание глав для чтения без сети (или свайпом по главе). Список и размер — «Аккаунт → Управление загрузками».
  Если сети нет, на экране тайтла показываются скачанные главы.
- Энергосбережение (вручную или вместе с режимом iOS): меньше разрешение, без предзагрузки и анимаций,
  экран может гаснуть, загрузка в один поток.
- Цвет акцента (Аккаунт → Цвет акцента).
- Оптимизация под устройства с 1 ГБ памяти (iPad mini 2, iPhone 5s/6): страницы режутся на полосы,
  декодируются по одной, кэши ограничены и чистятся сами.
- Читалка: «Лента», «Страницы →», «Страницы ←», зум, закладки, «Недавние», отметки прочитанного.
- Диагностика: журнал действий, причина вылета показывается при следующем запуске.

## Известные ограничения
- WebP на iOS 10 не открывается (нужна отдельная библиотека).
- Эндпоинты неофициальные (см. «ПРОВЕРИТЬ» в Config.swift и API.swift). Особенно: описание тайтла
  (`titleDetails` в API.swift) — если поля не совпадут, блок «О тайтле» покажет только название.
